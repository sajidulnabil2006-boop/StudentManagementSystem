# Student Management System

A desktop-based Student Management System developed using Java and JavaFX. The application provides a simple graphical interface for managing student information.

## Features

- Add new student
- View student information
- Search for students
- Update student information
- Delete student records
- Store student data in a file
- User-friendly JavaFX graphical interface
- Display student details including:
  - Name
  - Student ID
  - Department
  - CGPA

## Technologies Used

- Java
- JavaFX
- FXML
- IntelliJ IDEA
- File Handling
